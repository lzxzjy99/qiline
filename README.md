# 弈合 · 网页与桌面共用棋局（v0.11.0）

规则版本 `2.1.0-r3`。9 / 13 / 15 / 19 路、默认对角线、固定五子延迟四手、三手换色、PSK；可切换延迟、方向和同色换线继承。支持同设备双人、离线人机练习、在线多局房间与棋谱复盘续下。

v0.11.0 AI 里程碑大跃升（`v25` **极速纯 NNUE WASM SIMD128 内核** + **`Gen-6.3-192`** SE-ResNet 蒸馏棋形网络，对 `v0.10.0` 官方 100 局等时胜率 **`88.0%` / `+346.1 Elo`**）：
- **`v25` 极速纯 NNUE 搜索引擎内核**：彻底剥离叶节点 `View::compute()`，改用单子 `O(1)` 气速算 + 单遍 `FastLeaf` + 32 字节 2-Way 缓存行对齐置换表（262K 槽位、128 位防碰撞哈希、缓存静态估值）+ 前沿节点轻量 `MoveView` + 宽静着排序（单开 `+wide` 经消融实测即提升 `+181.3 Elo`）；在网络规模扩大 `2.7×` 的前提下，原生 AVX-512 实局仍提速 `1.40×`（单核峰值 `>1.0M NPS`），WASM SIMD128（`68.4 KB`）实测提速 `1.22×–1.25×`（单核 `593k NPS`）；
- **`Gen-6.3-192` SE-ResNet-10 蒸馏棋形神经网络（`NNUE v4`）**：升级至 `1638` 维稀疏特征（`486` 点气 + `800` 气感知/打吃破窗 5 窗口 + `64` 5 窗口孔型 + `288` 四区 2×2 围棋棋形）+ `16` 维零成本稠密特征 → `192 → 4 桶 × (32 → 16 → 1)` 三层 SCReLU（Float16 内联 `689 KB`，`rms=0.000031`）；经两轮 `30k` / `40k` 节点 `24,000` 局超深自博弈（总计 **140 万局面**）与 3 代 10 层 SE-ResNet 教师（8×-D4 TTA 软标签，`val_loss=0.3502`）多代知识蒸馏；
- **严格等时跨代双端实测验证**：
  - 原生 AVX-512 100 局纯等时（`1.5s/手`，无节点上限）直连冻结 `v0.10.0`：**`88 胜 12 负 0 和`（`88.0%` / `+346.1 Elo`，执 A `43/50`、执 B `45/50`）**；
  - Node/V8 WASM SIMD128 32 局实装 Float16 等时（`1.0s/手`，由生产 `packages/core` 裁判）直连冻结 `v0.10.0` WASM：**`27 胜 5 负 0 和`（`84.4%` / `+293.0 Elo`，执 A `14/16`、执 B `13/16`）**。

v0.10.0 AI 架构跨越升级（`v24` **WASM SIMD128** 原生计算内核 + **`Gen-5-128-B4`** 双倍宽度四阶段输出桶 NNUE）：
- **`v24` WASM SIMD128 零 GC 搜索内核**：将 `v23` 引擎与四阶段 SCReLU NNUE 完整重制为独立无依赖 C++20 / WASM SIMD128 模块（内联仅 `51.6 KB`，支持 `f32x4` 向量化推理、跨手热表与 8 核 Lazy SMP `SharedArrayBuffer` 共享置换表，老旧环境自动平滑降级纯 JS）；单核实测速度由 `v0.9.0` 纯 JS 的 `96.5k NPS` 跃升至 **`537k+ NPS`（提速 `5.6×`）**，8 核并行可达数百万 NPS；
- **`Gen-5-128-B4` 双倍宽度四阶段 SCReLU 神经网络**：凭借 `v24` 原生 AVX-512（`769k NPS/核`）高速生成 `8,000` 局 `20,000` 节点超深自博弈（新增 `232,119` 局面，总预训练池 `719,127` 局面），在 RTX 5070 上将隐藏层宽翻倍至 `128`（验证集准确率由 `77.89%` 提至 **`80.64%`**，`val_loss = 0.4010`）；同速度内核下 64 局等时对抗（`2.0s / 400k`）胜 `Gen-4-64-B4` **`41 胜 23 负`（`64.1%` / `+100.4 Elo`，执 A `20/32`、执 B `21/32`）**，且融合权重调优至 `0.88 / 0.50` 再胜 **`30 胜 18 负`（`+88.7 Elo`，A/B 各 `15/24`）**；
- **实际对局综合棋力飞跃**：叠加 `5.6×` WASM SIMD128 算力提速与 `Gen-5-128-B4` 权重增益，相对 `v0.9.0` 网页/桌面端综合棋力跃升约 **`+250～+350 Elo`**。

v0.9.0 AI 重大代际升级（`v23` + `Gen-4` 四阶段输出桶 NNUE）：
- **`v23` 静态空着剪枝（Reverse Futility Pruning）与动态控时**：在非 PV、无五连倒计时且局面平稳的浅层节点（`d ≤ 3`）引入经 112 局深算严格拆因验证的 `580×d` 稳健阈值 RFP（纯搜索相对 `v22s2` 取得 **`77 胜 35 负 / +136.8 Elo`**），并为满载交互长预算加入稳定优势早停动态控时；
- **`Gen-4-64-B4` 四阶段输出桶 SCReLU 神经网络**：采用 `v23` 自博弈生成的 `4,500` 局 `14,000` 节点超深局面（全预训练池 `487,008` 局面、五连倒计时局面扩容 8 倍，结合 D4 八重对称增强）在 RTX 5070 上训练 **4 阶段分桶输出头**（按盘面子数自动切分：开局/中盘/激战/官子，推理零速度税，Float16 内联仅 `125 KB`），同引擎下相对 `Gen-3-64` 权重再胜 **`32 胜 16 负 / +120.4 Elo`**；
- **64 局更深算总决战（`2.0s / 300k` 等时同种子）**：`v23 + Gen-4-64-B4 (0.82/0.45)` 击败现役冠军 `v22s2 + Gen-3-64` **`44 胜 20 负 0 和`（`68.8%` / `+137.0 Elo`，执 A `21/32`、执 B `23/32`，吞吐反升至 `109.4k NPS`）**，累计已领先 `v21`（40/40 胜 `0.5.11`）约 **`+245 Elo`**。

## 启动与构建

网站第15版已加入在线房间及测试棋谱导入回放。完整网站主入口为 https://qiline-online.pages.dev ，使用Cloudflare Pages、Pages Functions与原D1数据库，GitHub提交后自动发布，见[部署说明](docs/github-cloudflare.md)。原Workers入口保留备用；原Sites入口保留独立数据库。

需要 Node.js 22.12+（建议24）。先运行 `npm ci` 安装构建工具；网页规则与AI模块无外部运行时依赖。

```sh
npm run build
npm run check
npm test
```

完整网站的服务入口是 `dist/server/index.js`，包含原游戏、回放和在线房间。仅本地游戏及回放可用 `npm run build:static` 生成静态 `dist/` 托管；在线房间需要Worker与D1。不要直接双击 `file://` 页面。原Sites托管配置见 `.openai/hosting.json`，个人Cloudflare配置见 `wrangler.cloudflare.json`。

`compiled/core` 保持 P2 验证产物；`compiled/session` 仅扩展两处困难难度枚举／验证器。历史 P2 哈希不变，独立的 `node scripts/build-session-levels.mjs` 验证最小源码差异并重新编译会话，扩展清单由 `npm run check` 核对；未修改规则或任务权限。源码在 `packages/core`、`packages/session`。编译产物与源码须一同更新，不得只修改网页中的规则副本。

## 模块

- `packages/core`：不可变棋局、提子、五连、PSK 和完整重放。
- `packages/session`：真实玩家身份、共同同意和过期任务保护。
- `packages/ai`：AI 协议、完整棋谱重建、基础战术、迭代加深 Alpha-Beta、预算，以及 P5.4 独立 Worker 调度、实际终止和重试。
- `packages/ui/ai-host.mjs`：网页与 Electron 共用的模块 Worker 宿主；P5.5 产品入口管理其启动、暂停、重试和销毁。
- `packages/ui/ai-recovery.mjs`：产品层有限自动重试与等待状态；沿用 P5.4 任务权限和终止逻辑。
- `packages/ui/model.mjs`：中文展示、存档外壳、存储冲突保护。
- `apps/web`：响应式棋盘、浏览器入口、文件导入导出和内置手册。
- `scripts/build-web.mjs`：复制已验证的核心和网页资产，生成静态目录。
- `tests/web.test.mjs`：网页模型、展示和存档检查。
- `tests/product-matrix.test.mjs`：P5.10 的 2,688 个产品配置检查；测试条件与范围见对应报告。
- 其他测试、fixtures、reports、examples 和 docs/API.md 保留 P2 验证资料。P2 历史报告不代表网页和 Windows 验收结果。

## 存档与权限

自动保存使用 `localStorage`，包含完整显式命令，不信任最终棋盘。恢复严格重放；共同同意、提示授权和任务句柄不会恢复。导入支持本网页存档、当前版本会话存档与规则棋谱；支持一个人类与一个 AI 的非竞技练习存档，拒绝旧版、损坏、双 AI 或竞技 AI 存档。原始规则棋谱恢复为双人局。导入文件上限 5 MB，仅是本网页文件读取限制，不是对局手数上限。

活跃双人局禁止直接重开或替换；开局须双方同意取消，正常行棋可由任一方认输。悔棋请求在页面上交由对方回应。本地双人只基于共同遵守操作身份，不提供联网身份认证或反作弊。

人机练习可选简单／标准／困难，并明确选择人类担任 A、B 或随机分配。三手换色时 A 摆三子、B 选色；关闭换色时 A 执黑。人类和 AI 始终绑定各自的 A/B 身份，选色不交换姓名与控制者。困难存档需要 v0.5.8 或之后版本，旧简单／标准存档可继续恢复。练习支持暂停、继续和有限失败恢复：可恢复错误最多自动重试两次，仍失败时显示手动重试入口。

界面悔棋撤回最后两条显式命令及各自派生的自动停手；只有一条时撤回一条。练习退回 AI 回合时等待手动继续；双人局的整次撤回须对方同意。替换进行中的练习须确认；恢复练习存档后等待明确继续。具体操作见 [人机界面 P5.5](docs/AI人机界面P5.5.md)。

存储失败时继续保留内存棋局并提示导出；每次写入先保留上一份存档。同一浏览器多标签页采用存储事件与写前比较，旧标签页停止操作，保留导出入口，不覆盖新数据。
