# 弈合 · 网页与桌面双人（P4 候选包 / v0.4）

规则版本 `2.1.0-r3`。9 / 13 / 15 / 19 路、默认对角线、固定五子延迟四手、三手换色、PSK；可切换延迟、方向和同色换线继承。只支持同设备两人轮流操作。

## 启动与构建

需要 Node.js 22.12+。此静态网页版没有运行时第三方依赖，也不需要安装依赖。

```sh
npm run build
npm run check
node --test tests/web.test.mjs
```

将 `dist/` 用 HTTP(S) 静态服务托管，入口 `index.html`。不要直接双击 `file://` 页面：浏览器会限制 ESM 模块。托管配置见 `.openai/hosting.json`。

`compiled/core` 和 `compiled/session` 为已经通过 P2 验证的编译产物；本轮没有修改规则或会话内核。源代码在 `packages/core`、`packages/session`。需要改动内核时，使用 TypeScript 7.0.2 按 `tsconfig.json` 编译至 `dist/`，验证后将对应 `dist/core`、`dist/session` 同步至 `compiled/`，再执行静态构建。编译产物与源码必须一同更新；不得只修改网页中的规则副本。

## 模块

- `packages/core`：不可变棋局、提子、五连、PSK 和完整重放。
- `packages/session`：真实玩家身份、共同同意和过期任务保护。
- `packages/ai`：P5.1 AI 协议、完整棋谱重建、任务提交边界及存档适配；尚无选点算法或后台计算。
- `packages/ui/model.mjs`：中文展示、存档外壳、存储冲突保护。
- `apps/web`：响应式棋盘、浏览器入口、文件导入导出和内置手册。
- `scripts/build-web.mjs`：复制已验证的核心和网页资产，生成静态目录。
- `tests/web.test.mjs`：本轮 10 项宿主与展示检查。
- 其他测试、fixtures、reports、examples 和 docs/API.md 保留 P2 验证资料。P2 历史报告不代表网页和 Windows 验收结果。

## 存档与权限

自动保存使用 `localStorage`，包含完整显式命令，不信任最终棋盘。恢复严格重放；共同同意、提示授权和任务句柄不会恢复。导入支持本网页存档、当前版本会话存档与规则棋谱；拒绝旧版、损坏或人机存档。导入文件上限 5 MB，仅是本网页文件读取限制，不是对局手数上限。

活跃双人局禁止直接重开或替换；开局须双方同意取消，正常行棋可由任一方认输。悔棋请求在页面上交由对方回应。本地双人只基于共同遵守操作身份，不提供联网身份认证或反作弊。

存储失败时继续保留内存棋局并提示导出；每次写入先保留上一份存档。同一浏览器多标签页采用存储事件与写前比较，旧标签页停止操作，保留导出入口，不覆盖新数据。
