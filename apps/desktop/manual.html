围棋式提子，五连确认获胜。
推荐：9 路、对角线、延迟 4 手、三手换色、固定五子、全局禁重复。

Windows 快速开始

  1. 把整个 ZIP 解压到一个文件夹，不能只取出单个 exe。
  2. 双击文件夹中的 弈合.exe，点击“新对局”，选择“同设备双人”或“人机练习”，填写名字并选规则。
  3. 按界面提示摆三子、选色，然后轮流落子。默认仅对角线，五连还要保持后续四手。

这是 x64 Windows 候选包，内含运行库；设计为完全离线运行，无需安装 Node.js 或另开网页。尚未在 Windows 真机验收。不要将“构建完成”理解为所有 Windows 环境均已验证。

存档与导出

自动保存位于当前 Windows 账户的 %APPDATA%\QiLine，与程序解压位置分开。移动程序文件夹时仍使用同一自动存档；网页与桌面版各自保存，互通请使用导出／导入 JSON。不要在程序运行时删除自动存档目录。

展开“棋谱与存档”，点“导出存档”后在系统对话框选择路径；点“导入存档”选回 JSON 文件。双人进行中须先结束本局才能导入；人机练习可在确认替换后载入另一局。错误或旧版记录不会替换当前对局。若自动保存失败，请保持游戏打开并手动导出。关闭程序会先确认；刷新或重启后未处理的共同同意请求须重新发起。

窗口、缩放与手册

菜单“显示”可放大、缩小、恢复原始大小或切换全屏。完整规则在游戏右上角“玩法手册”内，无需联网。本文件也可独立打开阅读。包内 DLL、resources、locales 等文件均属于运行库，请保持完整。

像围棋一样吃子，像五子棋一样连线。
默认只算对角线，五连要守满后续 4 手。

01 · 开局

点击“新对局”选择棋盘和规则。默认 A 连续摆黑、白、黑三子，均不能提子；B 看过布局后选择执色，随后白走。A/B 是本局角色，玩家身份不因选色改变。关闭三手换色则黑先。

人机练习

选择“人机练习”后可选简单／标准，并指定自己担任 A 摆局或 B 选色。AI 在本机的后台线程运行，无需联网；A/B 控制者不因选黑选白而交换。AI 思考时可查气、暂停或结束对局。恢复人机存档后，先核对棋盘，再点击“继续对局”。

悔棋一次撤回最后两条明确操作，只有一条时撤回一条；选色也算一条，自动停手跟随所属操作撤回。退回 AI 回合后等待点击继续。AI 计算故障会暂停并有限自动重试，失败后仍可手动重试、查看和导出，不能把故障当作停手或认输。人机不提供竞技模式或双 AI 对局。

02 · 提子

同色棋子通过上下左右连成棋块；棋块相邻的空交叉点是“气”。落子后，先同时提走所有无气的对方棋块，再检查己方是否有气。自杀手与重复历史棋盘的落子会被拒绝。提子不额外获得一手，也不按提子数判胜。

03 · 五连确认

默认在任一对角线上连续五子后，形成候选；形成这手不计入延迟。随后对方走 1 手、己方走 1 手，再各走 1 手：原五子始终在盘，则第 4 手确认胜利。落子与停手都计手，查气、选色、非法操作和申请不计手。

每组固定五子独立计时。六连含两组五子，后加的一组重新计时；某组有子被提，该组取消。开启“换线继承”则每色一个候选，只要每次行动后该色始终有五连，新线可接替旧线。0 手档两种模式均为成五即胜。双方长连都有效，没有黑棋禁手。

04 · 停手与结束

无候选时双方连续停手，和棋；有候选时继续倒计时，优先结算胜利。无合法落点会自动停手。正常行棋时任一玩家可随时认输，非自己回合也可操作；摆局和选色阶段须双方同意取消。终局不能悔棋改判。

05 · 同意、查气与保存

休闲双人悔棋须对方回应；一次撤回最后两条玩家命令及其自动动作，只有一条时撤回一条。竞技不允许悔棋或取消开局。点击“查气”再点棋子，可看整块与气；不会落子或计时。点击“手数”显示落子序号。棋盘支持方向键与 Enter / 空格；大棋盘在小屏幕可横向滚动。

桌面自动保存，重启可恢复。导出与导入使用 JSON 存档，必须完整校验重放；可恢复双人与单 AI 练习，原始棋谱恢复为双人，竞技 AI、双 AI、旧版及损坏存档会被拒绝并保留当前局。双人须正常结束后才能替换；人机可在确认后替换或重开。自动保存失败会提示，请手动导出。清除浏览器数据可能删除本地进度。
