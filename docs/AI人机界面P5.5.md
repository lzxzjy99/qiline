# AI 人机界面 · P5.5

2026-10-21。本阶段在既有“弈合”网站接入一人对一台 AI 的练习入口，保留同设备双人入口。规则保持 `2.1.0-r3`，沿用 P5.4 Worker 宿主与 P5.3 搜索，不改规则、会话内核或 AI 算法。

## 新局与开局身份

新局支持“双人”和“人机练习”。练习可选择简单／标准难度，以及人类担任 A、B 或随机分配。选择结果绑定到本局真实玩家，换色不会交换姓名或控制者。

| 设置 | 行为 |
| --- | --- |
| 人类担任 A | 人类操作 A，AI 操作 B |
| 人类担任 B | AI 操作 A，人类操作 B |
| 随机分配 | 创建新局时确定一次 A/B 身份，界面明确展示结果 |
| 开启三手换色 | A 连续摆黑、白、黑三子，B 选择执色，随后由白棋先行 |
| 关闭三手换色 | A 执黑、B 执白，黑棋先行 |

难度继续使用既有 `easy`／`standard` 策略；时间、节点和深度预算见 [搜索与预算 P5.3](AI搜索与预算P5.3.md)。难度是本局 AI 设置，不能视为棋力评级。三手摆局和选色均按真实 A/B 身份推进，AI 可能连续操作，页面不能简单按黑白或动作次数交换控制者。

## 对局操作与权限

棋盘和选色入口仅在轮到人类、会话可操作且未发生存储冲突时开放。AI 操作期间显示任务状态；人类不能代 AI 落子、选色、停手或响应双人同意请求。AI 结果仍由 Session 与规则引擎重验，界面不直接修改棋盘。

| 操作 | 人机练习 | 同设备双人 |
| --- | --- | --- |
| 暂停／继续 | 终止当前 Worker；明确继续后创建新任务 | 沿用既有会话权限 |
| 失败重试 | 失败后由用户主动重试，不自动循环重试 | 不适用 |
| 悔棋 | 撤回最后一条显式命令及其派生自动停手；退回 AI 回合时等待明确继续 | 继续由对方同意，竞技模式沿用禁用规则 |
| 新建／重开 | 替换进行中的练习前确认 | 活跃局继续锁定；先按规则取消开局或结束对局 |
| 导入替换 | 先校验文件；替换进行中的练习前确认 | 活跃局继续锁定 |
| 认输 | 由人类按会话权限提出，AI 不自动认输 | 沿用当前操作身份与会话权限 |

悔棋单位是“最后一次显式操作”，包含不增加手数的选色，并非固定撤销一人一 AI 两步。悔棋到人类回合时允许继续操作；到 AI 回合时保持等待，防止刚撤回的操作立即被 AI 重做。

练习的新局、导入和重开使用本地确认，不能为双人局绕过共同同意或竞技锁定。双人取消开局、悔棋、认输等继续走既有 Session 流程。

## 保存与恢复

继续使用 `webSchemaVersion:1` 网页外壳和 `SessionSave` v1。外壳保存玩家姓名、A/B 映射、局数与快照标记；会话保存完整显式命令、控制者、难度和种子。存档以严格重放恢复，不信任最终棋盘，不保存有效任务、结果、暂停状态、同意请求、授权或计时器。

| 输入 | 恢复方式 |
| --- | --- |
| 网页外壳中的双人会话 | 保留玩家元数据，恢复双人局 |
| 网页外壳中的合法练习会话 | 保留玩家元数据、AI 身份、难度和种子，恢复练习局 |
| `SessionSave` v1 | 校验控制者与竞技设置，恢复双人或一个人类与一个 AI 的非竞技练习 |
| 当前规则版本的原始 `MatchRecord` | 默认恢复为双人局 |
| 双 AI、竞技 AI、旧版或损坏数据 | 拒绝导入，保留当前棋局 |

自动恢复和文件导入完成后，人机对局先保持等待；用户明确继续才开放人类操作或开始新的 AI 任务。恢复不沿用旧任务令牌，旧结果不能对恢复后的棋局生效。文件读取上限仍为 5 MB，不是对局手数上限。

自动保存沿用上一份备份、写前比较和跨标签页冲突保护。每次棋局变化仅保存一次，任务状态更新不覆盖备份。写入失败时保留内存棋局并提示导出；检测到其他标签页更新后暂停宿主，终止当前线程并停止后续调度，保留导出入口。

## 宿主生命周期

人机练习通过 `createBrowserAI` 连接既有 `AIWorkerController`。页面操作统一通过宿主的 `change()` 与已有 Session 命令提交；暂停、继续和重试使用现有调度接口。

新建、重开、成功读档会替换会话，先关闭旧宿主，再为新会话创建宿主。`pagehide` 同样关闭宿主，终止线程并清除定时器；从浏览器缓存返回时重新载入存档。存储冲突暂停宿主并锁定继续入口。读档后保留等待，不因创建新宿主而自动计算。旧回调、重复结果和已失效任务继续由 P5.4 的关联字段与任务令牌保护。

Worker 启动失败、硬超时或无可信结果时，棋局不自动停手或认输，界面显示失败并提供手动重试。后台搜索、实际终止和两层超时的细节见 [后台任务 P5.4](AI后台任务P5.4.md)。
