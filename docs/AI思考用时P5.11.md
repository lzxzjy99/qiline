# AI 思考用时 · v0.5.11

人机对局控制区显示“本手已思考”，以 0.1 秒更新，超过一分钟显示分、秒。AI 完成一次落子、停手或选色后显示“上一手用时”；三手摆局和选色后的连续行动分别计时。完成后的最后一次用时可保留至本局结束。

计时从主页面收到实际思考状态开始，到结果处理或停止思考为止，使用单调时钟。它是用户侧观察到的累计思考时间，包含主页面处理结果前的消息等待，不是 CPU 占用时间，也不是引擎内部报告的搜索耗时。准备、暂停、自动重试间隔均不累计；同一手暂停后重新计算或重试的实际思考时间会累计。

悔棋会清除已失效的用时；换局、导入、刷新恢复不会继承计时。该显示只保存在当前页面内存中，存档格式不变。计时更新仅改动用时文字，不重绘棋盘、不写自动存档。用时节点独立于状态播报区，避免读屏每 0.1 秒播报一次。

验证：`node --test tests/p55-app.test.mjs tests/web.test.mjs tests/desktop.test.mjs tests/ai-recovery.test.mjs`，72 项通过。新增 6 项应用入口检查覆盖分钟显示、实时更新、暂停与恢复、重试、过期结果、悔棋、读档、连续开局操作和终局保留。`npm run build`、`npm run check` 通过，30 个 JavaScript 模块完成检查，AI 与规则核心哈希保持原值。

真实浏览器使用原生模块 Worker 验证了困难 AI 实时计时、暂停后冻结，以及标准 AI 完成行动后保留耗时。手机底部用时文字通过应用入口自动检查；本轮未进行手机真机或窄屏截图验收。网页与 Electron 共用源文件，本轮没有重新打包 Windows 发行 ZIP。

本轮仅增加展示功能，保留已确定的 9×9、延迟 4 手 AI 优化基准，没有修改搜索、难度预算或对战结果。
